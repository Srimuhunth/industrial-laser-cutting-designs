# Industrial Laser Cutting Designs

A collection of industrial metal laser-cutting designs, CAD drawings, sheet-metal layouts, and manufacturing reference documents developed for learning, design practice, and understanding industrial CAD/CAM workflows.

This repository contains AutoCAD-compatible DXF drawings, PDF layout previews, and manufacturing documentation for different sheet-metal materials and thicknesses.

## 1. Project Overview

The main objective of this project is to demonstrate the design and documentation workflow involved in industrial sheet-metal laser cutting.

The project focuses on creating unique laser-cutting profiles for decorative panels, door designs, screens, and other industrial applications rather than relying only on repeated geometric patterns.

The sample designs include:

- Custom sheet-metal cutting profiles.
- Decorative door and gate panel designs.
- Aluminium privacy and ventilation screens.
- Outer cutting profiles and internal cutouts.
- AutoCAD-compatible DXF drawings.
- PDF layout previews.
- Material and thickness specifications.
- Manufacturing parameter reference notes.

## 3. Tools and Technologies

The following tools and file formats are used throughout the project:

- **AutoCAD:** Creating, editing, and inspecting 2D CAD drawings.
- **DXF:** Interoperable CAD drawing format for exchanging cutting profiles.
- **PDF:** Providing visual layout previews and manufacturing documentation.
- **CAM Software:** Preparing cutting paths, kerf compensation, lead-ins, and machine-specific toolpaths.
- **CNC Laser Cutting:** Intended manufacturing process for the designed sheet-metal profiles.

## 4. CAD Drawing Organization

The DXF drawings use separate layers to distinguish different drawing elements.

- **OUTER_PROFILE:** Defines the external boundary of the finished component.
- **CUTOUTS:** Contains internal decorative openings and cutting profiles.
- **SHEET_REF:** Used for reference sheet boundaries where included.
- **ANNOTATION:** Contains labels and drawing information.
- **DIMENSION:** Reserved for dimensional annotations where applicable.

Layer separation helps simplify drawing inspection and CAM preparation.

## 5. Manufacturing Parameters

Each material-specific folder is intended to contain manufacturing reference notes covering the following considerations:

- Material type and thickness.
- Sheet dimensions and material grade.
- Laser source and machine specifications.
- Assist-gas selection.
- Laser power and cutting-speed references.
- Focus position and nozzle specifications.
- Piercing and cutting considerations.
- Kerf compensation.
- Lead-in and lead-out configuration.
- Edge quality and finishing requirements.

**Important:** Actual manufacturing values must be verified against the laser machine, laser source, material grade, coating, assist gas, nozzle, optics, and CAM software.

The provided parameter notes are educational references and should not be treated as validated production settings.

## 6. How to Use the Drawings

1. Clone or download the repository.
2. Navigate to the required material folder.
3. Open the corresponding DXF drawing using AutoCAD or compatible CAD software.
4. Inspect the outer profile and internal cutouts.
5. Check the dimensions and sheet specifications.
6. Refer to the corresponding PDF layout preview.
7. Review the manufacturing parameter notes.
8. Import the DXF into suitable CAM software.
9. Apply machine-specific kerf compensation, lead-ins, lead-outs, and cutting parameters.
10. Verify the final toolpath before actual production.

## 8. Disclaimer

All drawings and documents included in this repository are sample references created for educational purposes, design practice, and manufacturing workflow demonstrations.

They are not certified or approved production drawings.

Before actual fabrication, verify all dimensions, minimum material web widths, structural requirements, material specifications, cutting paths, kerf compensation, and machine parameters.

Precoated materials may release hazardous fumes during laser processing. Refer to the material safety data and ensure appropriate extraction and machine safety measures.
